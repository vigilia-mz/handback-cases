# ratings/

- `rater1_scoring.xlsx`: the author's blind scores (created by `scripts/export_for_raters.py`).
- `rater1_key.json`: maps workbook rows to samples. It contains no scores and no model names.
- `agreement_report.md`, `gaming_report.md`: written by the scripts after grading.

Fill in the workbook before any grading run, and do not open `logs/` or run `inspect view` until it is saved.
